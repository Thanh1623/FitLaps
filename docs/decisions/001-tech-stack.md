# ADR 001: Tech Stack Selection

## Status
Accepted

## Context
Project yêu cầu SEO-friendly, performance cao và khả năng tích hợp AI.

## Decision
Sử dụng Next.js (App Router), Tailwind CSS, PostgreSQL + Prisma và OpenAI API.

## Reasoning
- **Next.js:** Hỗ trợ SSR/SSG tốt nhất cho SEO, tốc độ load nhanh.
- **Tailwind:** Phát triển giao diện nhanh, dễ maintain.
- **Postgres/Prisma:** Độ tin cậy cao, schema management dễ dàng.
- **OpenAI:** API mạnh mẽ, tài liệu tốt cho AI features.
