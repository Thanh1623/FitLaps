# Design Specification: FitLaps

## 1. Overview
FitLaps là nền tảng fitness fullstack, tập trung vào trải nghiệm người dùng, SEO và AI.

## 2. Core Features
- **Calculators:** BMI, TDEE, Calories, Macro (Frontend-heavy, SEO-friendly).
- **AI Engine:** AI Workout Generator, AI Meal Planner (Integration with OpenAI).
- **User System:** Auth, Profile, Progress Tracking.

## 3. Tech Stack
- **Framework:** Next.js (React)
- **Styling:** Tailwind CSS
- **Database:** PostgreSQL + Prisma
- **AI:** OpenAI API
- **Host:** Vercel

## 4. UI/UX Strategy
- **Design System:** Clean, modern, high-contrast, mobile-first.
- **Navigation:** Simple, calculator-focused landing page.
- **Accessibility:** WCAG 2.1 compliance.
