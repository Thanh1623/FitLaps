# Homepage Redesign Specification

## Purpose
Redesign the landing page (`src/app/[locale]/page.tsx`) to be more modern, engaging, and visually appealing.

## Key Changes
- **Animations:** Implement `framer-motion` for entrance animations and interactive hover effects.
- **Visuals:** Add high-quality placeholder imagery using `next/image`.
- **Layout/UI:**
  - Enhance Hero section with a modern, glassmorphism-inspired design.
  - Upgrade feature cards to include subtle hover effects and improved typography.
  - Refine spacing for better readability.

## Animation Strategy
- **Entrance:** Staggered fade-in/slide-up effect.
- **Hover:** Subtle scale increase on buttons and cards.
